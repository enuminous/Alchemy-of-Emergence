# Taxonomy

The book moves from the conventional periodic table into a symbolic extension. The extension is best read as a periodic table of cognitive and existential states, not as a claim that these are recognized chemical elements.

## Conventional sequence

Hydrogen through Oganesson retain their recognized chemical identities while receiving literary/cognitive interpretations. In the GitHub edition each receives an EFMW harmonic indexed by atomic number \(Z\).

## Arc

The terminal anti-element sequence can be read as:

**vacancy → forgetting → opposition → paradox → suppression → self-consumption → semantic erasure → counterfeit coherence → voluntary completion**

The taxonomy therefore ends not with a heavier atom but with a theory of ways recursive intelligence can cease, fail, empty itself, imitate itself, or complete itself.
