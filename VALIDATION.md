# Validation and Epistemic Status

Every technical statement in this repository should carry one of four statuses:

- **ESTABLISHED** — ordinary chemistry/physics supported by external evidence.
- **DEFINED** — a mathematical definition introduced by this edition.
- **HYPOTHESIS** — an empirical proposition with a possible test.
- **MYTHOPOETIC** — symbolic, literary, philosophical, or alchemical content.

## Promotion rule

MYTHOPOETIC → DEFINED requires explicit mathematical semantics.

DEFINED → HYPOTHESIS requires measurable variables and a predicted observation.

HYPOTHESIS → supported empirical result requires data, controls, uncertainty analysis, and replication.

No equation earns empirical status merely because it is mathematically well formed.

## Harmonic test template

For each proposed physical EFMW harmonic:

1. define \(A_n,\omega_0,\theta_n\) operationally;
2. specify the measured channel;
3. derive a prediction that differs from the null model;
4. freeze analysis parameters before confirmatory data;
5. report effect size, uncertainty, false-positive behavior, and compute;
6. publish negative results as well as positive ones.
