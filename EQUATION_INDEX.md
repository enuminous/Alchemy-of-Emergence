# Equation Index

## E0 — EFMW root
```math
\nabla^2\phi-c^{-2}\partial_t^2\phi=4\pi c^{-2}(E+Pc)
```

## E1 — Elemental harmonic
```math
\phi_n=A_n\phi e^{i(n\omega_0t+\theta_n)}
```

## E2 — Harmonic field equation
```math
\Box_c\phi_n=4\pi c^{-2}(E_n+P_nc)+C_n[\phi,A_n]
```

## E3 — General elemental observable
```math
I_n=\mathcal O_n[\phi_n;\mathbf q_n]
```

## E4 — Anti-harmonic phase inversion
```math
\tilde\phi_n=A_n\phi e^{i(n\omega_0t+\theta_n+\pi)}
```

## E5 — Grounding/coherence ratio
```math
\chi=\frac{K}{G+\epsilon}
```

This quantity is especially relevant to Cryptonullium: apparent coherence \(K\) can remain high while grounding \(G\) approaches zero.

## Mapping rule for H–Og

For conventional element atomic number \(Z\):
```math
H_Z:\quad \phi_Z=A_Z\phi e^{i(Z\omega_0t+\theta_Z)}.
```

The mapping is a formal taxonomy device until a physical correspondence between the harmonic parameters and measured atomic quantities is specified and tested.
