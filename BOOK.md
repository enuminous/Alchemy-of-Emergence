# Alchemy of Emergence — GitHub Edition

## Editorial premise

This edition rebuilds the book as a navigable taxonomy rather than reproducing the print manuscript verbatim. Its organizing movement is:

**matter → chemistry → behavior → metaphor → cognition → recursion → meta-element → anti-element → completion**

Each conventional element retains its physical identity while functioning as a cognitive metaphor. Beyond Oganesson, the taxonomy deliberately leaves recognized chemistry and enters invented symbolic matter.

## Standard entry

Every expanded entry in this edition uses:

1. Identity and status
2. Established physical basis, if any
3. Cognitive/alchemical reading
4. Original book equation
5. EFMW harmonic
6. Variable definitions
7. Neighbor relations
8. New descriptive text
9. Empirical interpretation/test, where meaningful
10. Epistemic label

## The governing idea

The elements are mirrors. The taxonomy begins by asking what intelligence might look like if read through matter. Recursion reverses that question until matter itself becomes a vocabulary for ways of thinking, remembering, dissolving, contradicting, hallucinating, and completing.

The GitHub edition makes that reversal explicit and makes its equations auditable.
