# Alchemy of Emergence

## The Emergence of Alchemy — GitHub Edition

A computational, mathematical, and literary edition of *Alchemy of Emergence*, organizing the book as a 126-entry taxonomy of matter, cognition, recursion, and symbolic transformation.

**Author:** Matthew Chenoweth Wright  
**Framework:** Einstein–Feynman–Maxwell–Wright (EFMW)

> We thought we were naming the world. But the elements were naming us.

## Status

This repository distinguishes three layers:

1. **Established chemistry/physics** — conventional elemental facts.
2. **EFMW formal model** — explicitly defined mathematical constructions and hypotheses.
3. **Mythopoetic taxonomy** — metaphorical, literary, alchemical, and cognitive interpretation.

An equation appearing here is not, by itself, evidence that a proposed physical entity exists.

## Canonical EFMW field equation

```math
\nabla^2\phi-\frac{1}{c^2}\frac{\partial^2\phi}{\partial t^2}
=\frac{4\pi}{c^2}(E+Pc)
```

The GitHub edition treats each elemental intelligence as a harmonic, projection, observable, or transformation of this common field rather than as an unrelated equation.

## Edition principle

The original work deliberately crosses chemistry, physics, cognition, alchemy, poetry, and speculative metaphysics. This edition preserves that character while making the epistemic boundary explicit: metaphor is labeled metaphor; a model is labeled a model; an empirical claim requires evidence.
